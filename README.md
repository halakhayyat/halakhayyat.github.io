# Hala Khayyat — Portfolio Website

A static, mobile-friendly portfolio. Open `index.html` to preview.

## Personalize
- **Profile photo:** save your own portrait as `assets/profile.jpg` (the HK monogram appears until then).
- **LinkedIn:** add your real profile URL to `LINKEDIN_URL` at the top of `script.js`. The LinkedIn link is hidden until added.
- **Certificates:** seven certificate files and optimized previews are included under `assets/certificates/`. Only publish these if you are comfortable making the documents publicly accessible.
- **Projects:** six project summaries are included; links and photos are optional.

## Publish on GitHub Pages
1. Create a **public** GitHub repository named `halakhayyat.github.io`.
2. Upload the **contents of this folder** (index.html, style.css, script.js, assets/) to the repository root.
3. In Settings → Pages, select **Deploy from a branch**, `main`, `/ (root)` and Save.
4. Visit `https://halakhayyat.github.io` after deployment completes.

The GitHub Pages repository and its files are publicly visible. Check certificates for private data before uploading.
